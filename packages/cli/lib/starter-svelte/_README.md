# __APP_NAME__

SvelteKit 2 + Svelte 5 Runes + Tailwind CSS 4 + Convex generated by Rahman Resources.
The scaffold uses `@sveltejs/adapter-node` for self-hosted/Dokploy-compatible output and includes the official `convex-svelte` client adapter.

## npm

```bash
npm install --legacy-peer-deps --include=dev
npm run check
npm run build
npm run dev
```

## Bun

```bash
bun install
bun run check
bun run build
bun run dev
```

Convex functions live under `src/convex/` as recommended by the Convex Svelte integration. Set `PUBLIC_CONVEX_URL` when you want the root layout to call `setupConvex()`; the starter still builds without a configured backend.

Install any canonical active slice with the explicit Svelte distribution:

```bash
npx rahman-resources@latest add appshell --framework sveltekit
# or
bunx rahman-resources@latest add appshell --framework sveltekit --package-manager bun
```

The CLI records the selected framework/package manager in `rr.json`. Framework-neutral services reuse their TypeScript source; UI slices use native `.svelte` renderers where required.
