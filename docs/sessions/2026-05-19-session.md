## Process notes

- **Pre-push hook runs `npm run build`** — catches cacheComponents +
  Turbopack issues that tsc misses. Saved us several times this session.
- **200-LOC modularity cap.** Audit blocks push on any file > 200
  LOC. This session extracted: `CrudRowActions` (from CrudListView),
  `feature-context-effect` (from feature-context), `admin-nav-items`
  (from admin-sidebar), `feature-bar-open-button` (from feature-bar).
  Standard pattern: when a single component grows past cap, pull
  helpers to neighbour file.
- **Changelog discipline.** Every wave adds an entry to
  `lib/content/changelog.ts` with bullets `{ text, slug, kind }` so
  `RecentlyUpdatedBadge` fires on the touched slice/template. Skipping
  this means the catalog can't surface "what's fresh".
- **Wave letter collisions.** Two agents ran in parallel today; both
  wrote to changelog. Convention: if "AW" is taken, use next free
  letter (AX, AY). Past letters stay attributed to whoever shipped
  first. AR-skip is intentional (AO/AQ for notion lift, AP for fix).
