## 1. Slice reusability — shadcn-parity (P0–P5 + P2/P3)

Goal: make `frontend/slices/*` as reusable as shadcn `components/ui/*`.

| Lever | Before | After |
|---|---|---|
| `className` merge | raw interpolation (`` `… ${cls}` ``) — consumer overrides left BOTH classes, CSS source-order decided silently | `cn(defaults, className)` everywhere (twMerge — last wins) |
| cn source | mixed `rahman-shared/lib/utils` + `@/lib/utils` | normalized to `@/lib/utils` (69 files) |
| Variant API | hand-rolled `cond ? "a" : "b"` | exported `cva` recipes: `heroCtaVariants`, `tokenStatusVariants`, `segmentItemVariants` |
| Props passthrough | none | `...props` (React-19 ref-as-prop) on every host-facing leaf: FileUploadButton, FullWidthToggle, InsertBlockButton, PageActionsMenu |
| Copy / i18n | Indonesian strings hardcoded | prop-driven `copy` objects, English defaults (full-width-toggle, doku-checkout, chat-fab) |
| Scaffold template | shipped `slice.json` only → new slices failed `audit:slices` on first run | ships the full trio (`slice.json` + `slice.contract.ts` + `slice.manifest.json`) + cn/`...props` parity demo |
| Lint guard | none | `audit:slices` flags raw-interp className + hardcoded hex (advisory, wired into pre-commit + pre-push) |

## 5. Docs-site page layout (Q2)

**Before** — every page hand-rolled its own header + container:
- 7 different inline header blocks (eyebrow/title/desc copy-pasted with slight drift).
- 7 pages double-constrained width (`max-w-3xl` on top of the shell that already
  applies it).
- changelog escaped padding with a `-mx-4` hack; architecture + stack used `text-4xl`
  h1 while everyone else used `text-3xl`; root spacing flipped `space-y-6` / `space-y-8`.

**After**
- One `<PageHeader>` component (eyebrow → title → description) on 8 content pages.
- Redundant `max-w-3xl` stripped from 7 pages — `DocsShell` owns width.
- `-mx-4` removed; h1 normalized to `text-3xl`; roots normalized to `space-y-8`.
- `build` deliberately left as a compact tool-toolbar (it's an app surface, not a doc).

Commit: `ba5c75a`.

> Deferred on purpose: **Q3** (extract 70+ inline card/section patterns) is internal
> dedup with *zero* visual change — not worth the churn/risk now. **Q4** font-serif
> removal was **cancelled** — hero + theme-presets actively use `font-serif`.

## 6. Global UI polish

| Detail | Before | After |
|---|---|---|
| Scrollbar | default chunky OS scrollbar (the visible annoyance) | **minimalist** — thin 8px track, ~4px hairline thumb (`--border` → `--muted-foreground` on hover), transparent track, theme-aware, Firefox + WebKit |

| Reduced motion | smooth-scroll + preset cross-fades always on | respects `prefers-reduced-motion` |
