# P2.6 — Next 15 → 16 Migration

After P2.5 (Clerk evicted). Source: superspace = Next 15. Target: Next 16 + Cache Components.

## Steps

1. **Bump deps**:
```bash
cd template-base
npm i next@latest react@19 react-dom@19
```

2. **`next.config.mjs`** — enable Cache Components:
```js
const nextConfig = {
  cacheComponents: true,
  deploymentId: process.env.NEXT_DEPLOYMENT_ID, // si-coder injects
  experimental: {
    serverActions: {
      allowedOrigins: ["yourdomain.com"],
      bodySizeLimit: "5mb",
    },
  },
  // ...preserve CSP from superspace
};
```

3. **`middleware.ts` → `proxy.ts`** — already done in P2.5 if rewritten there. Otherwise rename + adjust to Next 16 proxy contract (request-time boundary, not security boundary).

4. **`NEXT_SERVER_ACTIONS_ENCRYPTION_KEY`** — generate once, pin across instances:
```bash
openssl rand -base64 32
# Add to .env.example as placeholder + production .env (si-coder)
```
Audit-bp P0 if missing on multi-instance.

5. **`instrumentation.ts`** — add `register()` + `onRequestError`:
```ts
export async function register() {
  // OTel setup if applicable
}
export const onRequestError = async (err, request, context) => {
  // log to Sentry / Convex / etc
};
```

6. **`use cache` directive** — sweep server components doing heavy fetch; opt into `use cache` where stable.

7. **React 19 opportunities** (deferred, non-blocking):
   - `use(promise)` over `useEffect` + `setState` roundtrips
   - Ref-as-prop (drop `forwardRef` wraps for new components)
   - Taint APIs for sensitive data crossing server→client

8. **Validate**:
```bash
npm run build
npm run audit:bp -- --full
```
Target score ≥85.

## Breaking Surfaces to Check

- Pages using pre-16 `fetch` cache options (`cache: 'force-cache'`, `revalidate`) — migrate to `use cache`.
- Any route hitting Edge runtime expecting ISR (Edge does NOT support ISR — flag).
- `@vercel/og` users — verify Next 16 compat.
- next/image: confirm `remotePatterns` schema (Next 16 strict).
